V. KHUNG TIÊU CHÍ PHỎNG VẤN NHANH DÀNH CHO HR (HR SCREENING CHEAT-SHEET)
--------------------------------------------------------------------------------
1. Cấp bậc Intern / Fresher / Junior:
   - Ngôn ngữ Dart: Phân biệt `final` vs `const`, `var` vs `dynamic`, Null Safety.
   - Flutter Core: Phân biệt `StatelessWidget` và `StatefulWidget`.
   - Cơ chế phát triển: Phân biệt `Hot Reload` và `Hot Restart`.
   - Vòng đời: `initState()`, `build()`, `dispose()`.
   - Bố cục UI cơ bản: `Row`, `Column`, `ListView`, `Expanded`, `Flexible`.

2. Cấp bậc Middle:
   - Quản lý trạng thái (State Management): Hiểu sâu Provider, Riverpod, BLoC hoặc GetX; biết khi nào nên dùng loại nào.
   - Bất đồng bộ (Async): Sử dụng `Future`, `Stream`, `FutureBuilder`, `StreamBuilder`.
   - Quản lý bộ nhớ: Tránh memory leak bằng cách dispose `TextEditingController`, `StreamSubscription`, `AnimationController`.
   - Kết nối mạng & Lưu trữ: Xử lý RESTful API (`http`, `dio`), JSON serialization, SQLite, Hive hoặc SharedPreferences.
   - Custom UI & Animations: `CustomPaint`, `Hero`, `AnimationController`.

3. Cấp bậc Senior / Tech Lead:
   - Kiến trúc ứng dụng: Clean Architecture, MVVM, Dependency Injection (`get_it`).
   - Tối ưu hiệu năng (Performance): Giảm rebuild bằng `const`, Selector/buildWhen; xử lý danh sách dài, profile bằng Flutter DevTools.
   - Concurrency & Threading: Hiểu về Event Loop, Microtask Queue và sử dụng `Isolate` (`compute()`) cho các tác vụ nặng.
   - Native Integration: Viết Platform Channels (`MethodChannel`) để giao tiếp với iOS (Swift) và Android (Kotlin).
   - Kiểm thử & CI/CD: Viết Unit Test, Widget Test, Integration Test; thiết lập Fastlane, GitHub Actions.
