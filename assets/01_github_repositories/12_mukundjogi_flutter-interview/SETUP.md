# Setup Guide

This guide will help you set up the Flutter Interview Preparation repository on your local machine.

```

├── docs/                   # Documentation files
│   ├── introduction.md
│   ├── flutter-basics.md

│   └── ... (all topics)
```

## 📝 Development Workflow

### Making Changes

1. **Create a branch:**
   ```bash
   git checkout -b feature/my-feature
   ```

2. **Make changes to files**

3. **Commit changes:**
   ```bash
   git add .
   git commit -m "Add: Description of changes"
   ```

4. **Push and create PR:**
   ```bash
   git push origin feature/my-feature
   ```

## 📚 Reading the Documentation

You can read the documentation directly from the markdown files:

- Open any `.md` file in `docs/` folder
- Use a markdown viewer or editor
- View on GitHub when pushed

## 🛠️ Local Development

### Using a Markdown Viewer

You can use various tools to view the documentation:

1. **VS Code**: Install "Markdown Preview Enhanced" extension
2. **GitHub Desktop**: View files directly
3. **Online**: Push to GitHub and view there

### Testing Code Examples

All code examples are production-ready Dart/Flutter code. To test:

1. Create a Flutter project
2. Copy code examples
3. Run and verify they work
4. Experiment with modifications
